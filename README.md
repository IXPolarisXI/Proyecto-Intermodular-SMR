# Proyecto-Intermodular-SMR
## Documentación
Trabajo realizado por Alejandro Martin Arroyo, 1 SMR, IES Ribera del Tajo.

Mi proyecto consiste básicamente en el montaje, desmontaje y mantenimiento de un ordenador, explicando previamente los componentes más importantes de este, los distintos modelos y características que tiene cada uno, los distintos tipos de conectores, etc.

Después añadí una explicación simple con imágenes, pero útil, sobre cómo se realiza un buen mantenimiento, como se desmonta y se monta el ordenador, mencionando algunos errores comunes para evitar cometerlos.
Las fotos de este apartado las saqué de trabajos ya realizados, ya que no tengo ningún ordenador en mi casa para una mejor explicación.

No he utilizado ninguna herramienta adicional para poder realizar el trabajo.
El proyecto se puede resumir en una guía desde cero sobre un ordenador y sus componentes.
